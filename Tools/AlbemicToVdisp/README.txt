This tool creates a vdisp file from a given albemic (*.abc) file from Marvelous/CLO3D/Blender/Maya/etc
*should work with most albemic file versions but blender 4.5 & 5.0 abc exporter was used for testing*

!!REQUIRES BLENDER TO BE INSTALLED (either steam or standalone version) TESTED WITH BLENDER 4.5 and 5.0, should work with 4.0+!!

(all tools and vdisp format custom made with 💖 by Mathias)
